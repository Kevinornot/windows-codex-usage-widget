# v1.1.0

Privacy-safe public release of the Windows Codex Usage Widget.

## Downloads

- `windows-codex-usage-widget-portable-v1.1.0.zip` — portable source package; extract and run `run_widget.vbs`.
- `windows-codex-usage-widget-skill-v1.1.0.zip` — reusable Codex Skill and installation prompt.

Python 3.11 or newer and an installed Codex CLI are required for the portable source package.
